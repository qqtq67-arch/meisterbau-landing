# FEINWERK Berlin

Двуязычный статический лендинг с немецкой версией по умолчанию. Готовые файлы находятся в `dist/`. Для запуска достаточно статического HTTP-хостинга. Сборка и зависимости для запуска не требуются.

Демоверсия использует концептуальный бренд, географию и примеры цен. Изображения сгенерированы для сайта. Заявка формируется в браузере и доступна для копирования.

Перед публичным запуском обновите бренд, услуги и цены в `dist/index.html` и русских текстах `dist/site.js`. В `dist/settings.js` укажите действующие контакты и данные владельца. Для WhatsApp укажите международный номер цифрами, а для Telegram — имя пользователя без @. WhatsApp и электронная почта могут открыть готовый текст заявки. Телефон и Telegram показаны как ссылки для прямой связи. Сайт сам сообщения не отправляет. Добавьте утверждённые тексты Impressum и Datenschutz, отключите `preview`, обновите SEO-метаданные и правило индексации.
